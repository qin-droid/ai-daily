🥈 tamnd/kage — 离线网页快照，一键剥离所有 JS

⭐ 2,046 | Go

Kage 是一个轻量级的网页快照工具，它的独特之处在于——自动剥离网页中的 JavaScript，只保留纯净的 HTML 结构，生成一个干净、安全、永不过期的离线副本。

想保存一篇技术博客以防 404？需要批量存档网页但不想带一堆追踪脚本？Kage 完美解决。Go 语言编写，单文件运行，简洁到极致——这正是 UNIX 哲学的现代演绎。2046 颗星说明真的有人极度需要这个。

适合谁：知识管理者、安全研究者、需要批量存档网页内容的团队。如果你被现代网页的臃肿折磨过，你会爱上它。

关注理由：在 Web 越来越臃肿的今天，kage 反潮流而行——有时候做减法比做加法更需要勇气。
