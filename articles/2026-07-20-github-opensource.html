今天精选3个宝藏项目：AI把图片变3D模型、Agent工程标准指南、Mac硬件一键验机！

⭐ 1. hoainho/img2threejs

一张照片，AI帮你生成3D模型 — ⭐ 449 | Python

img2threejs 能根据参考图自动重建程序化的Three.js 3D场景。你丢一张建筑或物体的照片进去，它就能生成对应的三维模型，完全无需手动建模。从照片到3D，只需几秒钟。

为什么值得关注：3D内容创作的门槛从未如此之低。前端开发者、设计师、游戏爱好者都值得一试。

🔗 https://github.com/hoainho/img2threejs
🛠️ Python | ⭐ 449

⭐ 2. lopopolo/harness-engineering

AI Agent开发的"百科全书" — ⭐ 566 | Python

harness-engineering 系统整理了AI Agent工程领域的核心概念、架构模式、字段定义和最佳实践。无论你是刚接触Agent开发的新手，还是想规范团队实践的资深工程师，这个项目都能给你提供体系化的参考。

为什么值得关注：当大部分人还在"手写Agent"时，这里已经把Agent工程的标准化方案整理好了。开发者不用再重复踩坑。

🔗 https://github.com/lopopolo/harness-engineering
🛠️ Python | ⭐ 566

⭐ 3. andyhuo520/MacCheck

Mac硬件验机利器 — ⭐ 360 | Swift

MacCheck 是一款macOS本地硬件检测工具，一键生成详细验机报告。电池循环次数、屏幕坏点、硬盘健康度、内存规格——所有关键信息一目了然。买二手Mac不怕被坑，卖机器也能证明成色。

为什么值得关注：实用到爆的小工具。每个Mac用户都应该备一份。

🔗 https://github.com/andyhuo520/MacCheck
🛠️ Swift | ⭐ 360
