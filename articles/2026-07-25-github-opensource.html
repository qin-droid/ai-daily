⭐ 1. Vincentwei1021/video-shotcraft — AI视频制作Agent技能包

链接: https://github.com/Vincentwei1021/video-shotcraft

🔥 1,612 Stars | 🟦 TypeScript | 📜 Apache-2.0

这是一个给AI编程助手（Claude Code / Codex）用的"视频制作技能包"。你只需要用自然语言描述想要什么风格的视频，AI就能按照库里预置的106个电影级镜头模板、161种动效、完整配乐和音效方案，自动生成一段专业水准的产品宣传视频。简单说，它把"专业视频制作"这件事变成了"跟AI聊天"。

适用场景: 产品宣传片、App功能介绍视频、营销推广素材、技术Demo展示。

为什么值得关注: 1600+星一周内爆发，直接把AI Agent的能力从"写代码"扩展到了"做视频"。对内容创作者和创业者来说，等于免费请了一个视频制作团队。

⭐ 2. pireel/pireel — 开源AI视频编辑器，浏览器里做大片

链接: https://github.com/pireel/pireel

🔥 726 Stars | 🟦 TypeScript | 📜 AGPL-3.0

一款完全开源的AI视频编辑器，专为"讲话类视频"（talking-head video）打造。它集成了智能分镜、动态字幕、主题风格和WebCodecs本地渲染，全程在浏览器里运行，不需要后端服务器。最酷的是，它可以通过MCP协议被任何AI Agent操控——你可以让AI帮你剪视频。

适用场景: 自媒体口播视频、在线课程录制、产品演示、短视频批量生产。

为什么值得关注: 开源 + 纯前端 + AI驱动，打破了过去"做视频必须装Pr/FCP"的壁垒。730星证明市场对"AI视频民主化"的强烈需求。

⭐ 3. gnipbao/story-to-handdrawn-video — 文字秒变手绘动画视频

链接: https://github.com/gnipbao/story-to-handdrawn-video

🔥 620 Stars | 🟨 JavaScript | 📜 MIT

一个"Agent技能"——把你写的中文故事或图片，自动转换成手绘日记风格的动画短片。它生成的是无声的MP4画面轨道，每一帧都像手绘漫画一样可爱。特别适合把文字内容变成短视频发到抖音、小红书。

适用场景: 小红书/抖音内容创作、文学作品可视化、儿童故事动画化、社交媒体营销素材。

为什么值得关注: 纯中文场景 + 手绘风格差异化 + 极简操作。在"AI视频遍地走"的今天，它用"手绘日记"这个独特定位杀出了一条路。

📊 本周开源趋势

本周三大热门方向呼之欲出：AI视频创作工具（video-shotcraft、pireel 双双爆火）、Agent技能生态（越来越多人不是"造模型"而是给Agent"装插件"）、中文场景工具（story-to-handdrawn-video 说明中文开发者正在快速切入细分赛道）。
