一种全新的 Web 专属动画格式和运行时。核心思路是把"视频帧"变成"可独立解码的运动单元"，再配合一个小型状态机——用户悬停、点击、聚焦等操作不再是"跳到某时间点"，而是"状态机切换路线"。比 GIF 流畅、比视频灵活、不依赖视频播放器。

  • 📦 npm 即装即用：npm install @pixel-point/aval-element 即可使用
  • 🎨 轻量级：比 Lottie 更轻，比 MP4 更灵活

适合谁？ 前端开发者、UI/UX 设计师、想做高质量网页动效但不想用 GIF 或视频的人。
