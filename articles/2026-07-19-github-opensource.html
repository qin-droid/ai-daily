今天精选3个宝藏项目：用LLM在正常聊天中藏秘密、让所有AI Agent跑一个脚本、以及滚鼠标穿越3D世界！

⭐ 1. nethical6/conversation-steganography

LLM隐写术：在正常对话中隐藏消息 — ⭐ 688 | Go

conversation-steganography 是一个脑洞大开的工具——它利用LLM将秘密信息编码进看起来完全正常的对话文本中。你发送一句"今天天气真好"，背后却暗藏了一条加密消息。通过控制LLM输出的词汇模式来编码数据，旁观者只会看到一段普通聊天记录。

为什么值得关注：对隐私爱好者、安全研究人员来说，这是全新的"数字隐形墨水"——免费、开源、且极具创意。

🔗 https://github.com/nethical6/conversation-steganography
🛠️ Go | ⭐ 688

⭐ 2. PromptPartner/agentsmith

一个技能，在所有AI Agent上运行 — ⭐ 308 | Shell

agentsmith 是一套模型无关的AI Agent运行框架，支持Claude、Codex、Gemini等主流模型。你写一次任务脚本，在所有Agent上都能跑。提供统一的环境管理、权限控制和工具链集成，不再被某个特定AI编程工具"绑架"。

为什么值得关注：AI编程工具越来越多，但切换成本越来越高。AgentSmith让你自由切换底层模型，而不用重写工作流程。

🔗 https://github.com/PromptPartner/agentsmith
🛠️ Shell | ⭐ 308

⭐ 3. KubeezMedia/kubeez-scroll-world-video

滚动鼠标，穿越3D视频世界 — ⭐ 653 | JavaScript

kubeez-scroll-world-video 实现了视觉效果拉满的交互体验——滚动鼠标滚轮，屏幕上的3D世界就像"飞跃"一样推进。项目展示了如何用AI生成长视频并配合滚动交互，创造出在虚拟世界中飞行的沉浸感。

为什么值得关注：不仅是酷炫的Demo，更为品牌宣传页、游戏预告片和产品演示提供了全新的交互范式。

🔗 https://github.com/KubeezMedia/kubeez-scroll-world-video
🛠️ JavaScript | ⭐ 653
