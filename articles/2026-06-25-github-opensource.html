samasante/liquid-glass | ⭐ 311 | 🏷️ 前端 / React / UI

Apple 官网那种流动的毛玻璃效果，看着很高级对吧？这个开源项目把它做成了一个 headless React 组件，支持 Safari、Firefox 和 Chrome。不需要 WebGL 黑魔法，直接用 DOM 实现。

能做什么：给网站加上 Apple 风格的动态玻璃效果 | 沉浸式背景 + 前景内容自动融合 | 零配置，即插即用
