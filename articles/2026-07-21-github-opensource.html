今天精选3个宝藏项目：马斯克家的AI编码Agent开源、交互式视频的Web新格式、应用调用库的"降维打击"工具！

⭐ 1. xai-org/grok-build

SpaceX AI 出品的编码Agent — 全屏、鼠标交互、可扩展 — ⭐ 20.8k | Python

Grok Build 是 xAI 开源的一款 AI 编码 Agent，配备了完整的 TUI（终端用户界面）。支持全屏操作、鼠标交互、以及通过扩展系统自定义工作流。与 Codex CLI、Claude Code 等同类工具不同，Grok Build 强调终端内的沉浸式体验，让开发者无需离开命令行就能完成从代码生成到调试的全流程。

为什么值得关注：开源编码Agent赛道再添猛将。20k+星的数据说明社区对其高度期待。如果你想体验不同风格的AI编程助手，Grok Build 值得一试。

🔗 https://github.com/xai-org/grok-build
🛠️ Python | ⭐ 20.8k

⭐ 2. pixel-point/aval

让视频像网页一样可交互——新一代Web视频格式 — ⭐ 1.3k | JavaScript

Aval 是一种全新的开源 Web 交互式视频格式。它内置状态机、帧精确的过渡效果，以及 packed-alpha 透明通道支持。想象一下，视频不再是"播放-暂停"的线性体验，而是像网页一样可以点击、选择、分支交互——这就是 Aval 带来的变革。它特别适合产品演示、互动广告、教育内容等场景。

为什么值得关注：交互式视频是下一代内容形态的重要方向。Aval 提供了标准化的开源方案，前端开发者可以用熟悉的 HTML/CSS/JS 技能来制作互动视频，可能性无限。

🔗 https://github.com/pixel-point/aval
🛠️ JavaScript | ⭐ 1.3k

⭐ 3. littledivy/mimic

"截获"任何应用，然后用 Python 调用它 — ⭐ 1.4k | Python

mimic 让 Python 开发者可以截获（intercept）任意桌面应用的运行过程，然后用 Python 代码像调用库一样与之交互。不需要逆向工程、不需要模拟点击——直接把其他应用变成你的 Python 函数。无论是自动化老旧软件、提取其他应用的数据、还是做跨应用的流程编排，mimic 都提供了一条意想不到的捷径。

为什么值得关注：这个想法太"天才"了——与其用Selenium/DirectUI去模拟操作，不如直接从中间层截取并调用。Python自动化爱好者的神兵利器。

🔗 https://github.com/littledivy/mimic
🛠️ Python | ⭐ 1.4k
