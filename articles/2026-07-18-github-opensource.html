⭐ 1. xai-org/grok-build

全栈AI编程Agent终端框架 — 本周最热项目，3天狂揽1.6万星！

xAI（Elon Musk的AI公司）开源的 grok-build 是一个全屏交互式TUI框架，专为AI编程Agent打造。它提供了丰富的终端用户界面组件，让AI Agent能在终端中以更直观的方式与开发者交互——代码编辑、文件浏览、命令执行一气呵成。

为什么值得关注：xAI正在构建完整的开发者工具生态，grok-build对标Anthropic的Codex CLI但更注重终端体验。用Rust编写，性能极强，可扩展架构支持自定义插件。

🔗 https://github.com/xai-org/grok-build
🛠️ Rust | ⭐ 16,320

⭐ 2. littledivy/mimic

拦截任意应用，像调用Python库一样使用它 — 黑科技级别的进程间通信！

mimic 是本周Python领域最大亮点。它能拦截一个正在运行的应用程序，然后让你像调用Python函数一样从脚本中操控它——读取数据、触发操作、获取结果。

应用场景：想用Python自动化操作某个没有API的桌面应用？mimic直接搞定。从数据提取到自动化工作流，把任何GUI程序变成你的函数库。

🔗 https://github.com/littledivy/mimic
🐍 Python | ⭐ 1,148

⭐ 3. pixel-point/aval

Web交互视频新格式 — 这才是下一代视频该有的样子！

aval（Audio Video Assembly Language）是一种全新的Web交互视频格式。它内置状态机支持帧精确过渡，打包Alpha透明通道（RGBA视频），用TypeScript编写，适合在浏览器中创建可交互的视频内容。

为什么值得关注：普通视频是线性的，aval让你创建分支式、交互式的视频体验。非常适合教程、产品演示、游戏叙事等需要用户参与的场景。

🔗 https://github.com/pixel-point/aval
🌐 TypeScript | ⭐ 1,161
