⭐ 730 · +146/天 · Python

Claude 虽然有多模态能力，但直接扔一个视频进去，它只能看到零散的截图。这个项目解决了这个问题——它实现了场景感知 + 去重帧 + 语音转录的完整流水线：先分析视频中的场景变化，智能提取关键帧（而非每帧全抓），同时转录语音内容，最后把帧和文本一起喂给 Claude 进行理解。支持 URL 输入和本地文件，一键运行。对于需要分析长视频、监控视频、教学视频或影视内容的场景非常实用。
