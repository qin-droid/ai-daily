本周最值得关注的 3 个开源项目，开发者别错过

⭐ 1. Agent Apprenticeship — AI Agent 的"学徒制"训练营

Forsy-AI/agent-apprenticeship | ⭐ 681 | 🏷️ Python

让 AI Agent 从真实工作中学习的生态系统。不是让 Agent 按预设规则干活，而是像人类学徒一样——每完成一次任务就积累经验，多个 Agent 协同训练、互相学习、集体进化。干得越多，越聪明。

适合谁用：正在搭建 AI 自动化工作流的开发者，或想构建"越用越强"的 Agent 系统的团队。

为什么关注：它解决的是当前 AI Agent "干完就忘"的核心痛点。681 星的增长速度说明开发者非常买账"持续学习型 Agent"这个概念。

⭐ 2. Unlimited-OCR — 百度开源不限长度文字识别

baidu/Unlimited-OCR | ⭐ 377 | 🏷️ Python

百度将企业级 OCR 能力开源。市面上 OCR 工具很多，但能一次性完整处理几十页合同、几百页书稿的寥寥无几。Unlimited-OCR 不需要拆分再拼接，丢进去什么长度就完整解析什么长度。

适合谁用：需要批量处理长文档的开发者、做知识库和 RAG 数字化的团队、学术研究者。

为什么关注：免费 + 不限长度 + 百度品质。自建文档数字化管道的成本直接砍到零。

⭐ 3. Junction — VS Code 里的 AI 代理总控台

Plaer1/junction | ⭐ 525 | 🏷️ TypeScript

在 VS Code 侧栏一站式管理所有 AI 编码助手——Copilot、Claude Code、本地模型，统一入口、自由切换。告别在多个窗口间反复横跳的体验。

适合谁用：重度 AI 辅助编程的开发者、需要同时使用多个 AI 工具的工程师。

为什么关注：525 星说明"统一入口"是刚需。AI 编码工具越来越多，这种聚合器的价值只会越来越大。
