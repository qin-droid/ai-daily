⭐ 1. DNSGlobe — 全局DNS传播检测神器

🌟 Stars: 533 | 🛠️ 语言: Go | 📜 协议: MIT

DNSGlobe 是一个终端里的DNS检测工具，能在 34个全球DNS解析器 上同时检测你的域名解析情况，并以直观的可视化界面展示。修改DNS记录后经常要等半天才能全球生效，这个工具让你秒级看到哪个地区解析到了、哪个还没更新。

适用场景：

  • 网站迁移或换服务器后，验证DNS是否全球生效
  • CDN配置调试，确认各地区解析是否正确
  • DevOps 团队诊断域名解析故障

为什么值得关注？ 每天都有无数开发者在为DNS生效慢而头疼，这款工具把"等"变成了"看"，而且支持命令行一键使用。🔗 https://github.com/514-labs/dnsglobe

⭐ 2. Codex-X — Codex 桌面管理器

🌟 Stars: 377 | 🛠️ 语言: TypeScript | 📜 协议: MIT

Codex-X 是一款专为 OpenAI Codex CLI 设计的桌面管理工具，让你可以像管理多个终端窗口一样，同时运行、切换和管理多个 Codex 会话。支持 Codex Switch 和 Instruct 模式，界面简洁直观。

适用场景：

  • 同时处理多个编程任务，每个任务开一个独立的Codex会话
  • 需要对比不同Codex prompt的输出效果
  • AI编程重度用户的日常效率工具

为什么值得关注？ 随着 Codex CLI 用户越来越多，一款优秀的桌面管理器就成了刚需。Codex-X 解决了"只有一个终端窗口"的痛点。🔗 https://github.com/yynxxxxx/Codex-X

⭐ 3. Chromeless — "不存在的浏览器"

🌟 Stars: 239 | 🛠️ 语言: Swift | 📜 协议: MIT

一个脑洞大开的项目——一款 没有Chrome的macOS浏览器。它完全不依赖 Chromium/WebKit 等传统浏览器引擎，却能打开网页并完美渲染，专为 截图和全屏视频播放 而生。极简到极致，甚至没有地址栏。

适用场景：

  • 自动化网页截图，生成精美的网页快照
  • 全屏播放网络视频，没有浏览器UI干扰
  • 嵌入式环境需要轻量级网页渲染

为什么值得关注？ 当99%的浏览器都在越做越重时，Chromeless 反其道而行之，只做一件事并做到极致。🔗 https://github.com/antiwork/chromeless
