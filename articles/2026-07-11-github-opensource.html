⭐ 1. Texts-to-Transformer — 把你的聊天记录训练成 AI 模型

🌟 Stars: 336 | 🛠️ 语言: Python | 📜 协议: MIT

一个能在 Mac 上从零开始训练微型 Transformer 模型的工具，训练数据就是你自己的 iMessage 聊天记录。整个过程完全本地运行，数据不出门。它包含完整流程：安全导出聊天数据库、文本提取和匿名化、Tokenizer 训练、自定义 Transformer 模型（4层/138万参数）、MLX 训练、评估和终端聊天界面。没有任何预训练——连 Tokenizer 都是从零训练的。

关注理由： 🧠 从零训练 Transformer，无需预训练模型 / 📱 用自己的聊天数据，学会你的说话风格 / 🔒 全程本地运行，隐私有保障 / 🍎 专为 Apple Silicon 优化。🔗 https://github.com/Doriandarko/texts-to-transformer

⭐ 2. Pilotfish — 给 Claude Code 装个"省钱副驾驶"

🌟 Stars: 339 | 🛠️ 语言: - | 📜 协议: MIT

Claude Code 的多模型编排层。最强模型（Fable 5 / Opus）负责规划和决策，便宜模型（Sonnet / Haiku）负责执行机械性工作，验证环节再用新上下文确保质量。三个配置文件，全局安装，所有项目自动受益。Anthropic 官方测试显示：Fable 5 编排 + Sonnet 执行能达到全 Fable 性能的 96%，成本却只要 46%。

关注理由： 💰 省 Token 费：成本降低 58-74% / 🚀 一键安装，全局配置 / 🧪 官方测试验证 / 🔄 自动降级：最强模型不可用时无缝切换。🔗 https://github.com/Nanako0129/pilotfish

⭐ 3. FableCut — AI 也能剪视频的浏览器编辑器

🌟 Stars: 325 | 🛠️ 语言: JavaScript | 📜 协议: MIT

一个零依赖、完全在浏览器中运行的 Premiere 风格非线性视频编辑器。整个时间线就是一个 JSON 文档，AI Agent 可以通过 MCP/REST 接口直接操控它剪辑视频，人类可以在旁边看着时间线实时刷新。支持多轨道编辑、滤镜、色键抠像、关键帧动画、速度曲线、AI 人像分割等专业功能。

关注理由： 🎬 浏览器即开即用 / 🤖 AI Agent 可直接操控剪辑 / ⚡ 零 npm 依赖 / 👨‍👩‍👧 人机协作编辑同一时间线。🔗 https://github.com/ronak-create/FableCut
