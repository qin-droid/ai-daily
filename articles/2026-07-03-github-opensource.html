📈 HKUDS/Vibe-Trading — AI驱动的个人量化交易Agent

⭐ 17.3k · Python · MIT

🔗 https://github.com/HKUDS/Vibe-Trading

想让AI帮你炒股？Vibe-Trading 是一个集大语言模型（LLM）+ 量化交易 + 回测分析于一体的AI交易Agent。你只需用自然语言描述交易策略（比如"当MACD金叉且RSI<30时买入"），它就会自动执行回测、生成交易信号、可视化收益曲线。多Agent协作架构让策略开发、风险管理和执行各自独立。

推荐理由：零编程门槛玩量化交易！对想尝试AI+金融的普通投资者非常友好。LLM驱动意味着你不需要写代码，用大白话就能定义策略。适合对量化交易感兴趣但不想学编程的读者。
